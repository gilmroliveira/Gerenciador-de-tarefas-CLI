
# 📝 Gerenciador de Tarefas CLI - Dart

Este é um projeto simples de **Gerenciador de Tarefas (To-Do List)** desenvolvido em Dart, focado em praticar conceitos de **Programação Orientada a Objetos (POO)** e manipulação de listas.

O projeto foi construído para rodar diretamente no terminal (CLI), permitindo ao usuário gerenciar suas atividades diárias de forma rápida e intuitiva.

## 🚀 Funcionalidades

- [x] **Criar Tarefa:** Adicione um título e uma descrição opcional.
- [x] **Listar Tarefas:** Visualize todas as tarefas com ID, título e status (concluída ou pendente).
- [x] **Editar Tarefa:** Altere o título ou a descrição de uma tarefa existente através do ID.
- [x] **Concluir/Reabrir:** Alterne o status de conclusão de uma tarefa.
- [x] **Excluir:** Remova tarefas da lista permanentemente.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Dart
- **Paradigma:** Orientação a Objetos (Classes, Métodos, Atributos)
- **Interface:** CLI (Interface de Linha de Comando)
